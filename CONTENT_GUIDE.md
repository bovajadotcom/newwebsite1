## 🌐 Как редактировать текст на 3 языках

**Файл:** `artifacts/auto-site/src/lib/translations.ts`

Файл разделён на три секции — `en`, `pl`, `ru`. Каждая строка — это ключ и текст:

```
"nav.home": "Home",        ← английский (en)
"nav.home": "Strona Główna",  ← польский (pl)
"nav.home": "Главная",        ← русский (ru)
```

**Важно:** ключ (левая часть до `:`) должен быть одинаковым во всех трёх секциях. Меняйте только правую часть (текст в кавычках).

### Что где находится в translations.ts:

| Строки | Содержимое |
|---|---|
| Секция `en:` — строки ~3–125 | Весь английский текст |
| Секция `pl:` — строки ~129–250 | Весь польский текст |
| Секция `ru:` — строки ~253–374 | Весь русский текст |
| `nav.*` | Пункты навигации |
| `home.hero.*` | Главный баннер (заголовок, подзаголовок, кнопки) |
| `stats.*` | Цифры статистики (лейблы: "Авто доставлено" и т.д.) |
| `section.*` | Заголовки разделов на главной |
| `footer.*` | Подвал сайта |
| `contact.*` | Страница «Контакты» |
| `about.*` | Страница «О нас» |
| `services.*` | Страница «Услуги» |
| `pricing.*` | Страница «Цены» |
| `calc.*` | Калькулятор |

## 🚗 Как редактировать автомобили в наличии

**Файл:** `artifacts/auto-site/src/data/inventory.ts`

### Добавить новый автомобиль в наличии:

```typescript
{
  id: "v9",                          // уникальный ID, не повторять
  make: "Toyota",                    // марка
  model: "RAV4",                     // модель
  year: 2023,                        // год
  engine: "2.5L Hybrid",            // двигатель
  fuel: "Hybrid",                    // Petrol / Diesel / Hybrid / Electric
  transmission: "Automatic",        // Automatic / Manual
  mileage: 15000,                    // пробег в км
  location: "Osaka, Japan",         // где находится
  price: 45000,                      // цена в USD (число без знака $)
  description: "Текст описания...", // описание (на английском)
  status: "available",               // available / sold / reserved
  image: "vehicle-1.png",           // имя файла из папки public/
  badge: "New Arrival",             // необязательно: метка на карточке
},
```

### Статусы автомобиля:
- `"available"` — в наличии (зелёный)
- `"reserved"` — забронирован (синий)
- `"sold"` — продан (серый)

| `team-2.png` | Фото команды — член 2 |
| `team-3.png` | Фото команды — член 3 |

## ⚙️ Редактирование через CMS (без кода)

Открыть CMS: перейдите по адресу `/admin/`  
Логин: **admin** | Пароль: **admin123**

### Что можно менять в CMS:

**Settings (Настройки) — ставки калькулятора:**
- НДС по странам (Польша, Литва, Латвия, Эстония, Германия, Чехия)
- Доставка Западная Европа (€800 по умолчанию)
- Доставка Восточная Европа (€600 по умолчанию)
- Сервисная комиссия (€500 по умолчанию)

**Testimonials (Отзывы):**  
Добавляйте / редактируйте / удаляйте отзывы клиентов прямо в браузере.

**Services (Услуги):**  
Управление карточками услуг — название, описание, цена.

**Vehicles (Авто в БД):**  
Альтернативный способ добавить авто через форму (дублирует `inventory.ts`).

**Translations (Переводы):**  
Редактор переводов по ключам — удобнее для несрочных правок.

## 💡 Советы

- **Числа в калькуляторе (НДС, доставка)** — меняйте в CMS → Settings. Изменения вступают в силу сразу.
- **Ставки растаможки Беларусь** — в файле `artifacts/auto-site/src/config/customs-belarus.json`. Там таблицы ЕАЭС.
- **Новый язык** — добавьте секцию в `translations.ts` и добавьте кнопку в `Layout.tsx`.
- **Цифры статистики** (450+ авто, 8 лет опыта и т.д.) — ищите в `home.tsx` по словам `stats` или цифрам.
